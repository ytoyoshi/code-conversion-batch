=== アプリケーションの責務

本アプリケーションは、指定された入力ファイルを読み込み、パラメータで指定された変換先文字コードへ変換を行い、変換後データを出力するバッチアプリケーションである。

主な責務は以下の通りである。

* パラメータファイルの読み込みおよび内容チェック
* 変換先文字コードへの変換処理
* 出力ファイルの生成
* 終了コードの返却（正常終了/処理指示パラメータエラー/処理中エラー）

変換可能な文字コードは Java が Charset としてサポートするもの全てである。ただし、本アプリケーションで動作確認済みのコードタイプは以下とする。

* UTF-8
* EBCDIC (Cp930)
* JIS X 0201
* ISO-2022-JP

== 機能詳細

=== メイン処理

==== 処理契機

以下のコマンドを実行する。

[source,bash]
----
java -jar encoding-batch-1.0.0-jar-with-dependencies.jar ParameterFile.properties
----

ParameterFile.properties : 処理指示パラメータファイルを指定。拡張子は「.properties」とする。文字コードはUTF-8をサポートする。

==== パラメータ（パラメータファイル内容）

以下の項目を key=value 形式で定義する。

.パラメータ一覧
[cols="2,1,5", options="header"]
|===
|パラメータ名 |必須 |内容

|input.file.path
|○
|入力ファイルのフルパス

|output.file.path
|○
|出力ファイルのフルパス

|source.charset.single
|○
|変換元1バイト文字コード +
Java の Charset.forName() が受け付ける名称を指定する。

|source.charset.double
|FILE_C/D時○
|変換元2バイト文字コード +
Java の Charset.forName() が受け付ける名称を指定する。 +
FILE_C、FILE_D の場合は必須。それ以外は任意（指定しても無視）。

|target.charset.single
|○
|変換先1バイト文字コード +
Java の Charset.forName() が受け付ける名称を指定する。

|target.charset.double
|FILE_C/D時○
|変換先2バイト文字コード +
Java の Charset.forName() が受け付ける名称を指定する。 +
FILE_C、FILE_D の場合は必須。それ以外は任意（指定しても無視）。

|file.id
|○
|ファイル識別子 +
FILE_A, FILE_B, FILE_C, FILE_D, FILE_E, FILE_F のいずれかを指定する。
|===

コードタイプは自由入力であり、Java の Charset.forName() が受け付ける名称を指定する。

* UTF-8 を指定する場合 ... UTF-8
* EBCDIC を指定する場合 ... Cp930
* JIS X 0201 を指定する場合 ... JIS_X0201
* ISO-2022-JP を指定する場合 ... ISO-2022-JP

.処理指示パラメータファイルの作成例（FILE_C: UTF-8 → JIS混合）
[source,properties]
----
input.file.path=/data/in/sample_input.txt
output.file.path=/data/out/sample_output.txt
source.charset.single=UTF-8
source.charset.double=UTF-8
target.charset.single=JIS_X0201
target.charset.double=ISO-2022-JP
file.id=FILE_C
----

==== 返却値

* int : 終了コード (0/1/2/3/99)

.終了コード一覧
[cols="1,3", options="header"]
|===
|終了コード |説明

|0
|正常終了

|1
|コマンドライン引数エラー

|2
|パラメータ検証エラー

|3
|文字コード変換エラー

|99
|その他の予期しないエラー
|===

==== 処理内容

. コマンドライン引数からパラメータファイルパスを取得する。

. パラメータファイルを読み込み、key=value 形式でパースし、処理指示パラメータを生成する。
.. <<_処理指示パラメータの読み込みとチェック,パラメータのバリデーション>>を実行する。
.. エラーが存在した場合、エラーメッセージを出力し、終了コード 2（処理指示パラメータエラー）で終了する。
.. パラメータ内容をログ出力する。

. file.id の値に応じて、適切なファイル処理を選択する。
.. FILE_A または FILE_B の場合 → <<_全体変換処理file_a_file_b用,全体変換処理>>
.. FILE_C または FILE_D の場合 → <<_混合ファイル変換処理file_c_file_d用,混合ファイル変換処理>>
.. FILE_E または FILE_F の場合 → <<_可変長ファイル変換処理file_e_file_f用,可変長ファイル変換処理>>

. 選択したファイル処理を呼び出し、入力ファイルパスと出力ファイルパスを渡す。
.. 文字コード変換エラーが発生した場合、エラー内容をログ出力し、終了コード 3 で終了する。
.. その他のエラーが発生した場合、エラー内容をログ出力し、終了コード 99 で終了する。

. 終了コード 0 を返却し、処理を終了する。

=== 処理指示パラメータの読み込みとチェック

パラメータファイルの読み込み時に、自動的にバリデーションが実行される。

==== 処理契機

メイン処理からパラメータファイルパスを指定して呼び出される。

==== 処理内容

. プロパティファイルを読み込み、key=value 形式でパースする。

. 必須パラメータのチェックを行う。以下の項目が null または空文字の場合、例外をスローする。
.. input.file.path
.. output.file.path
.. source.charset.single
.. target.charset.single
.. file.id

. file.id の妥当性チェックを行う。
.. file.id が FILE_A ～ FILE_F のいずれかであることを確認する。
.. 不正な値の場合、IllegalArgumentException をスローする。

. 2バイト文字コードの必須チェックを行う（file.id の値に依存）。
.. FILE_C または FILE_D の場合
... source.charset.double が null または空文字の場合、IllegalArgumentException をスローする。
... target.charset.double が null または空文字の場合、IllegalArgumentException をスローする。
.. FILE_A、FILE_B、FILE_E、FILE_F の場合
... source.charset.double、target.charset.double は任意（未設定でも可）。

. 文字コードの妥当性チェックを行う。
.. source.charset.single, target.charset.single は常にチェックする。
.. source.charset.double, target.charset.double は値が設定されている場合のみチェックする。
.. Java の Charset.forName() で変換できない場合、UnsupportedCharsetException をスローする。

. サポートする文字コードの組み合わせチェックを行う。
.. source.charset.single, target.charset.single は常にチェックする。
.. source.charset.double, target.charset.double は値が設定されている場合のみチェックする。
.. 以下の文字コードのみサポート対象であることを確認する。
... UTF-8
... ISO-2022-JP
... JIS_X0201
... CP930 (IBM930)
.. 上記以外の文字コードが指定された場合、IllegalArgumentException をスローする。

. 漢字変換実施フラグを設定する。
.. FILE_C または FILE_D の場合
... source.charset.double と target.charset.double が異なる（大文字小文字を無視）場合、convertDoubleByteCharset を true に設定する。
... 同一の場合は false に設定する（漢字変換をスキップ）。
.. FILE_A、FILE_B、FILE_E、FILE_F の場合
... convertDoubleByteCharset を false に設定する。

. パラメータ内容をログ出力する（ファイルID、入出力パス、変換元/先文字コード、漢字変換実施）。

. 読み込んだパラメータを返却する。

=== ファイル変換ユーティリティ（FileConversionUtil）

==== 概要

ファイルタイプ別の変換ロジックを提供する静的ユーティリティクラス。

入出力処理は含まず、バイト配列の変換のみを行う。

各Converterクラス（WholeFileConverter、MixedFileConverter、VariableLengthConverter）から呼び出される。

==== 公開メソッド

===== convertWholeFile

全体変換（FILE_A、FILE_B用）。

====== パラメータ

* inputBytes: 入力バイト配列
* sourceCharset: 変換元文字コード
* targetCharset: 変換先文字コード

====== 返却値

* 変換後バイト配列

====== 処理内容

. CodeConverter.convertCharset() で全体を一括変換する。

. ヘッダーレコードのコード区分を変換する。
.. 210バイトごとにレコードを区切る。
.. 1バイト目が'1'（ヘッダーレコード）の場合、6バイト目のコード区分を更新する。
... 変換先がEBCDIC（CP930等）の場合：'1'に設定
... 変換先がJIS/UTF-8の場合：'0'に設定

. 変換後バイト配列を返却する。

===== convertMixedFile

混合ファイル変換（FILE_C、FILE_D用）。

====== パラメータ

* inputBytes: 入力バイト配列
* config: MixedFileConversionConfig（変換設定）
.. sourceCharsetSingle: 変換元1バイト文字コード
.. sourceCharsetDouble: 変換元2バイト文字コード
.. targetCharsetSingle: 変換先1バイト文字コード
.. targetCharsetDouble: 変換先2バイト文字コード
.. convertDoubleByteCharset: 漢字変換実施フラグ

====== 返却値

* 変換後バイト配列

====== 処理内容

. 変換元文字コードがUTF-8かどうかを判定する。

. UTF-8の場合
.. convertMixedFileCharacterBased() を呼び出す（文字数ベース処理）。

. UTF-8以外の場合
.. convertMixedFileByteBased() を呼び出す（バイト数ベース処理）。

. 変換後バイト配列を返却する。

===== convertVariableLengthFile

可変長ファイル変換（FILE_E、FILE_F用）。

====== パラメータ

* inputBytes: 入力バイト配列
* sourceCharsetSingle: 変換元1バイト文字コード
* targetCharsetSingle: 変換先1バイト文字コード

====== 返却値

* 変換後バイト配列

====== 処理内容

. 変換先文字コードがEBCDICかどうかを判定する。

. BDWを読み込んでブロック単位で処理する。
.. ブロック長を取得する。
.. ブロックデータを読み込む。
.. processBlock() でブロックを変換する。
.. 新しいBDWを計算して変換後ブロックを構築する。

. 全ブロックの変換後バイト配列を返却する。

==== 内部メソッド

NOTE: 内部メソッドの詳細は実装を参照。主要なメソッドは以下の通り。

* convertMixedFileCharacterBased(): UTF-8文字数ベース変換
* convertMixedFileByteBased(): バイト数ベース変換
* convertSimpleRecord(): シンプルレコード変換（ヘッダー/トレーラー/エンド）
* convertDataRecordCharacterBased(): データレコード変換（文字数ベース）
* convertDataRecord(): データレコード変換（バイト数ベース）
* processBlock(): 可変長ブロック処理
* processRecord(): 可変長レコード処理
* convertControlCharacter(): 制御文字変換

=== 全体変換処理（FILE_A / FILE_B用）

==== 概要

1バイト文字のみで構成されるファイルを全体一括変換する。

FILE_A と FILE_B は同一の処理ロジックを使用する。

固定長レコード（210バイト）で構成され、ヘッダー/データ/トレーラー/エンドレコードを含む。

変換後、ヘッダーレコードのコード区分を変換先文字コードに応じて更新する。

==== ファイル構造

.レコード構造（210バイト固定長）
[cols="1,1,3", options="header"]
|===
|位置 |サイズ |内容

|1バイト目
|1 byte
|レコード区分 +
'1' = ヘッダーレコード +
'2' = データレコード +
'8' = トレーラーレコード +
'9' = エンドレコード

|2バイト目
|1 byte
|データ種別（データレコードの場合） +
'1' または '2'

|6バイト目
|1 byte
|コード区分（ヘッダーレコードの場合） +
'0' = JIS/UTF-8 +
'1' = EBCDIC

|3-210バイト目
|208 bytes
|レコードデータ
|===

==== パラメータ

* param : BatchParameter（処理指示パラメータ）


==== 返却値

なし（ファイル出力）

==== 処理内容

. 処理開始ログを出力する。

. 入力ファイル全体を読み込む。
.. java.nio.file.Files.readAllBytes() を使用してファイル全体をバイト配列として読み込む。

. FileConversionUtil.convertWholeFile() を呼び出してファイル変換を実行する。
.. 引数：入力バイト配列, sourceCharsetSingle, targetCharsetSingle
.. 返却値：変換後のバイト配列
.. 詳細は <<_ファイル変換ユーティリティfileconversionutil,ファイル変換ユーティリティ>> を参照。

. 変換後のバイト配列を出力ファイルに書き込む。
.. java.nio.file.Files.write() を使用してファイルに書き込む。

. 処理完了ログを出力する。

=== 混合ファイル変換処理（FILE_C / FILE_D用）

==== 概要

1バイト文字と2バイト文字（漢字）が混合するファイルを変換する。

FILE_C と FILE_D は同一の処理ロジックと漢字項目定義を使用する。

レコード単位で処理を行い、データレコードの特定フィールドのみ漢字変換を実施する。

**重要**: 変換元文字コードがUTF-8の場合は文字数ベースで処理し、それ以外（JIS、EBCDIC等）はバイト数ベースで処理する。

===== 文字数ベース処理（UTF-8用）の詳細

NOTE: 以下は FileConversionUtil 内部で実行される処理の詳細。実際の処理は FileConversionUtil.convertMixedFileCharacterBased() で行われる。

. 入力ファイルをInputStreamReader（UTF-8エンコーディング）で開く。

. 出力ファイルを開く。

. 以下の処理をファイル終端まで繰り返す。
.. レコード区分（1文字目）を先読みする。
.. レコード区分に応じて読み込む文字数を決定し、残りを読み込む。
... データレコード（'2'）の場合
.... データ種別（2文字目）をさらに先読みする。
.... データ種別に応じた残り文字数を決定する。
..... データ種別='1'：残り348文字（計350文字）を読み込む
..... データ種別='2'：残り298文字（計300文字）を読み込む
.... データレコード変換処理（文字数ベース）を実行する。
... ヘッダー/トレーラー/エンドレコードの場合
.... 残り379文字（計380文字）を読み込む。
.... シンプルレコード変換処理を実行する。
... 上記以外：警告ログを出力し、レコードをそのまま出力
.. 変換後レコードを出力ファイルに書き込む。

. ファイルをクローズする。

. 処理完了ログを出力する（総レコード数、ヘッダー数、データ数、トレーラー数、エンド数）。

===== バイト数ベース処理（UTF-8以外用）の詳細

NOTE: 以下は FileConversionUtil 内部で実行される処理の詳細。実際の処理は FileConversionUtil.convertMixedFileByteBased() で行われる。

. 入力ファイルをBufferedInputStreamで開く。

. 出力ファイルを開く。

. 以下の処理をファイル終端まで繰り返す。
.. 380バイト分のレコードを読み込む。
.. レコード区分（1バイト目）を判定する。
.. レコード区分に応じて変換処理を実行する。
... ヘッダーレコード（'1'）：シンプルレコード変換処理を実行
... データレコード（'2'）：データレコード変換処理（バイト数ベース）を実行
... トレーラーレコード（'8'）：シンプルレコード変換処理を実行
... エンドレコード（'9'）：シンプルレコード変換処理を実行
... 上記以外：警告ログを出力し、レコードをそのまま出力
.. 変換後レコードを出力ファイルに書き込む。

. ファイルをクローズする。

. 処理完了ログを出力する（総レコード数、ヘッダー数、データ数、トレーラー数、エンド数）。

==== シンプルレコード変換処理

ヘッダー、トレーラー、エンドレコード用の変換処理。文字数ベースとバイト数ベース両方で共通使用。

. レコードデータ（バイト配列）を受け取る。
.. 文字数ベース処理の場合：文字列をバイト配列に変換してから渡す
.. バイト数ベース処理の場合：読み込んだバイト配列をそのまま渡す

. CodeConverter.convertCharset() を呼び出し、レコード全体を変換する。
.. 引数：レコード全体のバイト配列, sourceCharsetSingle, targetCharsetSingle
.. 返却値：変換後のバイト配列

. ヘッダーレコード（1バイト目が'1'）の場合、コード区分（6バイト目）を更新する。
.. 変換先文字コードがEBCDIC（Cp930含む）の場合：'1'を設定
.. 変換先文字コードがJIS/UTF-8の場合：'0'を設定

. 変換後のバイト配列を返却する。

==== データレコード変換処理（文字数ベース）

. データ種別（2文字目）を取得する。

. データ種別に応じた漢字項目定義（KANJI_FIELD_DEFS_CHARACTER）を取得する。
.. 定義が存在しない場合、レコード全体を1バイト文字として変換して返却する。

. 変換後レコードを構築する作業用バッファを準備する。

. 各フィールドを順次処理する（文字位置ベース）。
.. 漢字項目の前の1バイト文字部分を文字列として抽出する。
.. CodeConverter.convertCharset() で1バイト文字を変換する。
.. 変換後データを作業用バッファに追加する。
.. 漢字項目を文字列として抽出する。
.. convertDoubleByteCharset が true の場合
... CodeConverter.convertKanjiCharset() で漢字を変換する。
... 変換後データを作業用バッファに追加する。
.. convertDoubleByteCharset が false の場合
... 漢字項目をそのまま（変換せず）作業用バッファに追加する。

. 最後の漢字項目以降の1バイト文字部分を変換する。

. 作業用バッファの内容を返却する。

==== データレコード変換処理（バイト数ベース）

. データ種別（2バイト目）を取得する。

. データ種別に応じた漢字項目定義（KANJI_FIELD_DEFS_BYTE）を取得する。
.. 定義が存在しない場合、レコード全体を1バイト文字として変換して返却する。

. 変換後レコードを構築する作業用バッファを準備する。

. 各フィールドを順次処理する（バイト位置ベース）。
.. 漢字項目の前の1バイト文字部分をバイト配列として抽出する。
.. CodeConverter.convertCharset() で1バイト文字を変換する。
.. 変換後データを作業用バッファに追加する。
.. 漢字項目をバイト配列として抽出する。
.. convertDoubleByteCharset が true の場合
... CodeConverter.convertKanjiCharset() で漢字を変換する。
... 変換後データを作業用バッファに追加する。
.. convertDoubleByteCharset が false の場合
... 漢字項目をそのまま（変換せず）作業用バッファに追加する。

. 最後の漢字項目以降の1バイト文字部分を変換する。

. 作業用バッファの内容を返却する。

=== 可変長ファイル変換処理（FILE_E / FILE_F用）

==== 概要

可変長レコードファイルを変換する。

FILE_E と FILE_F は電文以外同じ構成であり、同一の処理ロジックを使用する。

ブロック単位・レコード単位で処理を行い、BDW・RDW・電文長を再計算する。

制御文字（終端符号）の変換も実施する。

==== ファイル構造

.ブロック構造
----
┌──────────────────────────┐
│ BDW (4 bytes)               │ ブロック長
├──────────────────────────┤
│ RDW (4 bytes)               │ レコード長
├──────────────────────────┤
│ 固定部 (26 bytes)           │ 8-33バイト目
├──────────────────────────┤
│ 電文長 (2 bytes)            │ 34-35バイト目
├──────────────────────────┤
│ 電文 (可変)                 │ 36バイト目以降
├──────────────────────────┤
│ 終端符号 (1 byte)           │ 0xB4 or 0x74
└──────────────────────────┘
----

* 1ファイル内に複数ブロックが連続して格納される。
* 各ブロックには上記構造のレコードが含まれる。

.フィールド詳細
[cols="2,1,1,3", options="header"]
|===
|フィールド名 |位置 |サイズ |内容

|BDW
|0-3
|4 bytes
|ブロック全体の長さ（BDW含む）

|RDW
|4-7
|4 bytes
|レコードの長さ（RDW含む）

|固定部
|8-33
|26 bytes
|英数のみ

|電文長
|34-35
|2 bytes
|電文部の長さ

|電文
|36-
|可変
|英数半角カナが含まれる

|終端符号
|末尾
|1 byte
|EBCDIC: 0xB4, JIS/UTF-8: 0x74
|===

==== 制御文字変換

終端符号は文字コードに応じて以下のように変換する。

.制御文字変換パターン
[cols="2,1,1", options="header"]
|===
|変換方向 |変換前 |変換後

|EBCDIC → JIS/UTF-8
|0xB4
|0x74

|JIS/UTF-8 → EBCDIC
|0x74
|0xB4
|===

==== パラメータ

* param : BatchParameter（処理指示パラメータ）


==== 返却値

なし（ファイル出力）

==== 処理内容

. 処理開始ログを出力する。

. 入力ファイル全体を読み込む。
.. java.nio.file.Files.readAllBytes() を使用してファイル全体をバイト配列として読み込む。

. FileConversionUtil.convertVariableLengthFile() を呼び出してファイル変換を実行する。
.. 引数：入力バイト配列, sourceCharsetSingle, targetCharsetSingle
.. 返却値：変換後のバイト配列
.. 詳細は <<_ファイル変換ユーティリティfileconversionutil,ファイル変換ユーティリティ>> を参照。

. 変換後のバイト配列を出力ファイルに書き込む。
.. java.nio.file.Files.write() を使用してファイルに書き込む。

. 処理完了ログを出力する。

NOTE: ブロック処理、レコード処理、BDW/RDW再計算の詳細は FileConversionUtil を参照。

===== ブロック処理の詳細

NOTE: 以下は FileConversionUtil 内部で実行される処理の詳細。

. 変換方向を判定する（targetCharsetSingleがCP930を含む場合、EBCDIC方向）。

. 入力ファイルを開く。

. 出力ファイルを開く。

. 以下の処理をファイル終端まで繰り返す（ブロック処理）。
.. BDW（4バイト）を読み込み、ブロック長を取得する。
.. ブロックデータ（BDWを除く）を読み込む。
.. レコード処理を実行する。
.. 変換後レコードから新しいブロック長を計算する。
.. 新しいBDWを構築する。
.. BDWと変換後レコードを出力ファイルに書き込む。

. ファイルをクローズする。

. 処理完了ログを出力する（総ブロック数）。

==== レコード処理

. RDW（4バイト）を読み込み、レコード長を取得する。

. 各フィールドを抽出する。
.. 固定部（26バイト）
.. 電文長（2バイト）
.. 電文（電文長で指定されたバイト数）
.. 終端符号（1バイト）

. 固定部を変換する。
.. CodeConverter.convertCharset() を呼び出す。
.. 引数：固定部バイト配列, sourceCharsetSingle, targetCharsetSingle

. 電文を変換する。
.. CodeConverter.convertCharset() を呼び出す。
.. 引数：電文バイト配列, sourceCharsetSingle, targetCharsetSingle

. 終端符号を変換する。
.. 内部メソッド convertControlCharacter() を呼び出す。
.. 引数：終端符号バイト配列, isToEbcdic
.. EBCDIC(0xB4) ⇔ JIS/UTF-8(0x74) の変換を実行

. 新しい電文長を計算する（変換後電文のバイト数）。

. 新しいレコード長を計算する。
.. RDW + 固定部 + 電文長フィールド + 電文 + 終端符号

. 変換後レコードを構築する。
.. 新しいRDW（4バイト）
.. 変換後固定部
.. 新しい電文長（2バイト）
.. 変換後電文
.. 変換後終端符号

. 変換後レコードを返却する。

== 業務共通クラス

=== CodeConverter

==== 概要

文字コード変換を行うUtilityクラス。

通常の文字コード変換と2バイト文字（漢字）の変換を提供する。

ISO-2022-JPのESCシーケンス処理にも対応する。

==== メソッド一覧

===== convertCharset

====== 概要

通常の文字コード変換を行う。

====== パラメータ

* sourceBytes : byte[] - 変換前バイト列
* sourceCharset : String - 変換元charset名
* targetCharset : String - 変換先charset名

====== 返却値

* byte[] - 変換後バイト列

====== 処理内容

. 入力バイト列が null または空の場合、空のバイト配列を返却する。

. sourceCharset で Charset オブジェクトを生成する。

. targetCharset で Charset オブジェクトを生成する。

. sourceBytes を sourceCharset でデコードして文字列を生成する。

. 文字列を targetCharset でエンコードしてバイト配列を生成する。

. 変換後バイト配列を返却する。

===== convertKanjiCharset

====== 概要

2バイト文字（漢字）の文字コード変換を行う。

ISO-2022-JPの場合、ESCシーケンスの付与・除去を行う。

====== パラメータ

* sourceBytes : byte[] - 変換前バイト列（2バイト文字のみ）
* sourceCharset : String - 変換元charset名
* targetCharset : String - 変換先charset名

====== 返却値

* byte[] - 変換後バイト列

====== 処理内容

. 入力バイト列が null または空の場合、空のバイト配列を返却する。

. 変換元が ISO-2022-JP の場合、ESCシーケンスを付与する。
.. ESCシーケンス付与処理（addEscSequence）を実行する。

. convertCharset() を呼び出して文字コード変換を実行する。
.. 引数：処理済みソースバイト配列, sourceCharset, targetCharset

. 変換先が ISO-2022-JP の場合、ESCシーケンスを除去する。
.. ESCシーケンス除去処理（removeEscSequence）を実行する。

. 変換後バイト配列を返却する。

===== addEscSequence（内部メソッド）

====== 概要

JIS X 0208の2バイトコードにESCシーケンスを付与する。

====== パラメータ

* kanjiBytes : byte[] - JIS X 0208の2バイトコード列

====== 返却値

* byte[] - ESCシーケンス付きバイト列

====== 処理内容

. 出力用バイトストリームを準備する。

. 漢字モードへのESCシーケンスを書き込む（0x1B 0x24 0x42）。

. 漢字データを書き込む。

. ASCIIモードへのESCシーケンスを書き込む（0x1B 0x28 0x42）。

. バイトストリームの内容を返却する。

===== removeEscSequence（内部メソッド）

====== 概要

ISO-2022-JPのバイト列からESCシーケンスを除去する。

====== パラメータ

* iso2022JpBytes : byte[] - ISO-2022-JPバイト列

====== 返却値

* byte[] - ESCシーケンス除去後の2バイトコード列

====== 処理内容

. 出力用バイトストリームを準備する。

. 入力バイト列を先頭から順次処理する。
.. 0x1B（ESC）を検出した場合、次の2バイトと合わせて3バイトをスキップする。
.. 上記以外の場合、バイトを出力用ストリームに書き込む。

. 出力用ストリームの内容を返却する。

=== ビルド・実行方法

# Mavenでビルド
mvn clean package

# 生成されるjar
# target/encoding-batch-1.0.0-jar-with-dependencies.jar

==== 実行

----
# 基本実行コマンド
java -jar encoding-batch-1.0.0-jar-with-dependencies.jar parameter.properties

# ログファイル
# カレントディレクトリに encoding-batch.log が生成される
----

=== エラーハンドリング

本アプリケーションは以下のエラーハンドリングを実施する。

. コマンドライン引数エラー
.. 引数が1つでない場合、使用方法を表示して終了コード1で終了

. パラメータ検証エラー
.. 必須パラメータ未指定
.. ファイルID不正
.. サポート対象外文字コード指定
.. 上記の場合、エラーメッセージを表示して終了コード2で終了

. 文字コード変換エラー
.. 変換処理中の例外発生
.. エラー内容をログ出力して終了コード3で終了

. その他の予期しないエラー
.. 上記以外のエラー発生
.. エラー内容をログ出力して終了コード99で終了

=== ログ出力

ログは以下の2箇所に出力される。

* 標準出力（コンソール）
* ファイル（encoding-batch.log）

ログレベルは INFO および DEBUG を使用する。

主要な処理単位でログを出力し、処理の追跡を可能にする。
